3. Capture separate test attempts

Choose the actual label before capturing. All three methods use the same saved landmarks for each attempt. Do not use reference captures as test attempts.

“New single” always uses reference capture 1, chosen by capture order rather than test performance. This helps separate the effect of collecting a new reference from the effect of averaging.

Start with 5 correct A attempts and 5 clearly wrong attempts. Keep hand, view and distance similar first. Add distance or opposite-hand tests afterward and record those conditions.
