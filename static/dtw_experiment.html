Moving-sign (DTW) experiment

Phase 3 prototype. Records a short burst of frames per attempt instead of one snapshot, then scores it against a reference recording with dynamic time warping. Not connected to any lesson or the live learning flow — purely for trying out thresholds.

Start your Flask app, then start the camera below.

1. Setup

The webcam is not mirrored. Each recording captures frames for about 2 seconds — start the motion right after pressing record, and keep your hand in view the whole time.

2. Record the reference motion

Perform the correct motion once, at a natural, comfortable speed. You can re-record this as many times as you like — only the latest reference is kept.

Not recorded

3. Record test attempts

Choose the actual label before recording, same as the static experiment — this keeps the label honest.

These defaults are not calibrated — this prototype has no saved test data yet to calibrate against. Record several correct and several wrong attempts (including some done faster/slower than the reference), then adjust slope/threshold and recompute to see what separates them.
