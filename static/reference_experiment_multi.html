Static sign reference experiment

Compare the original reference, new capture 1 alone, and the average of five captures on the same inputs.

Start Flask, then load the lesson list.

1. Select a static sign

Choose a lesson. If it has no saved reference, start with five new captures and compare the first capture with the average.

No lesson selected

Use one hand, similar distance, lighting and view for all five references. Match the original reference hand for this first experiment. Verify the pose against your lesson demonstration.

2. Capture five correct poses

The webcam is not mirrored. Hold the correct pose still, capture it, relax your hand, then form the sign again for the next capture.

Open “Show saved landmarks” beneath a photo to inspect the extracted points. Yellow dots and green lines show saved landmarks; previews do not change scoring.

The backend computes the averages after five captures.

3. Capture separate test attempts

Choose the actual label before capturing. All three methods use the same saved landmarks for each attempt. Do not use reference captures as test attempts.

“New single” always uses reference capture 1, chosen by capture order rather than test performance. This helps separate the effect of collecting a new reference from the effect of averaging.

Start with 5 correct A attempts and 5 clearly wrong attempts. Keep hand, view and distance similar first. Add distance or opposite-hand tests afterward and record those conditions.

Normalized settings (30 / 70) are provisional, not calibrated. Recompute after changing them. Original settings remain 300 / 70. Both modes use the same saved inputs. Invalid captures are excluded, not counted as wrong signs. This does not normalize rotation or handedness.

Finger bends: compare two joints per finger; use the largest finger error. Slope 1 and threshold 70 are pilot settings. This does not check thumb placement or the whole movement. The average column averages joint angles, not landmark coordinates.
